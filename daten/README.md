# Kartendaten

- `lenox.json` – Sicherungskopie von Lenox' Sammlung (Name, Set-Kürzel, Nummer, Variante, Seltenheit, Anzahl).
- `bilder/offiziell/` – offizielle Kartenbilder von TCGdex.
- `bilder/` – Fotos aus Lenox' Bildern (für Karten ohne offizielles Bild).
- Preise: Cardmarket-Trend über TCGdex (Stand im Feld `priceDate`).

Die Live-Daten liegen in der Datenbank der Kartensammlung-Seite (Anmeldung mit dem Sammlernamen „Lenox“).
Diese Kopie wird bei jedem Eintragen durch Claude aktualisiert.
